# 기능 요구사항 (FR)

기준일: 2026-10-26. 요구사항의 기준은 이 문서다. FinMATE 원본은 [참고 기록](../reference/13-functional-nonfunctional-usecases.md)으로 보존한다. 기존 FR 번호·정의·완료 조건을 유지하고 새 요구만 뒤에 추가했다. 기존 P0/P1/P2는 당시 범위 표시이며, 현재 출시 순서는 [로드맵](../product/learning-roadmap.md)이 정한다.

## 기존 기능

아래 표는 요구이며 구현 증거가 아니다. 기존 구현 상태·테스트 이름은 참고 기록 §10.2에 있고 현재 환경의 실행 결과는 별도 검증 증거로 남긴다. FR-20은 현재도 범위 밖이다. FR-16·17의 실데이터는 데이터 이용 권한을 확보한 뒤 진행한다.

| ID | 기능 | 액터 | 기존 우선순위 | 완료 조건 |
|---|---|---|---|---|
| FR-01 | 회원가입·로그인 | 사용자, 인증 인프라 | P0 | 유효한 계정으로 로그인하고 보호된 API에 접근한다. |
| FR-02 | 진단 가능 여부 확인 | 사용자 | P0 | 최근 진단 시각, 다음 가능 시각, 제한 사유를 조회한다. |
| FR-03 | 진단 질문·선택지 조회 | 사용자 | P0 | 활성 버전의 질문 순서와 선택지만 조회한다. |
| FR-04 | 진단 답변 제출 | 사용자, 규칙 엔진 | P0 | 모든 필수 문항을 검증하고 하나의 이력과 결과를 생성한다. |
| FR-05 | 투자 성향 판정 | 규칙 엔진 | P0 | 점수·5단계 성향·추천 카테고리를 서버 규칙으로 결정한다. |
| FR-06 | 판정 근거 설명 생성 | AI 설명 생성기 | P0 | 답변과 규칙 결과에 근거한 설명을 생성하고 실패하면 템플릿으로 완료한다. |
| FR-07 | 결과·근거·고지 조회 | 사용자 | P0 | 본인 결과만 조회하며 점수, 성향, 근거, 기준 버전, 면책 문구를 표시한다. |
| FR-08 | 카테고리·상품 탐색 | 사용자 | P0 | 자산군·위험등급별 목록과 상품 상세·확인 항목을 조회한다. |
| FR-09 | 진단 이력·변화 비교 | 사용자 | P1 | 과거 진단, 점수·성향·근거 버전의 변화를 비교한다. |
| FR-10 | 개념 트리·상품 학습 카드 조회 | 사용자 | P0 | 주식·채권·펀드·ETF·부동산·금·선물·옵션·마진·레버리지 등 개념을 계층으로 탐색하고 그림·오해·체크리스트·출처를 본다. |
| FR-11 | 개념별 확인 문제 풀이·채점 | 사용자, 규칙 엔진 | P0 | 개념마다 다른 문항을 풀고 선택지별 해설과 다음 학습 행동을 받는다. |
| FR-12 | 메커니즘 시뮬레이션 실행 | 사용자, 계산 엔진 | P0 | 금리·수수료·변동성·유동성·옵션·선물·레버리지 등의 가정값을 바꾸고 결과·가정·seed를 확인한다. |
| FR-13 | 교육용 포트폴리오 실험·비교 | 사용자, 계산 엔진 | P0 | 가상 상품 바구니와 충격 시나리오를 넣어 손익·낙폭·비용·유동성·자산별 기여도를 전후 비교한다. |
| FR-14 | 방법론·가정·출처 조회 | 사용자 | P0 | 계산식 버전, 데이터 기준 시각, 제외된 항목과 한계를 확인한다. |
| FR-15 | 학습 진도·오답노트 저장 | 사용자 | P1 | 로그인 사용자별 완료 개념, 시도·오답·마지막 복습일을 저장한다. |
| FR-16 | 실데이터 수집·정규화·스냅샷 | 운영자, 외부 데이터 공급자 | P1 | 허용된 API/문서를 수집하고 원문 URL·기준일·hash·지연·정규화 결과를 저장한다. |
| FR-17 | 과거 자료·사례 탐색 | 사용자, 운영자 | P1 | 기준일이 지난 공시·가격·사례를 현재 데이터와 분리해 비교한다. |
| FR-18 | 콘텐츠·상품·출처 검수·게시 | 운영자 | P1 | 초안→검수→게시→만료 상태와 변경 이력을 관리한다. |
| FR-19 | 데이터 신선도·오류 상태 안내 | 사용자, 운영자 | P1 | 지연·누락·출처 만료·계산 불가를 숨기지 않고 화면과 운영 화면에 표시한다. |
| FR-20 | 외부 계좌·주문 연동 | 사용자, 금융기관 | P2 | 별도 보안·규제·계약 검토가 끝난 뒤에만 추진한다. 현재 범위에서 제외한다. |
| FR-21 | 주식 용어 사전 | 사용자 | P0 | 14개 분류 247개 용어를 정의·설명·공식·예시·주의·관련 용어·연결 개념·출처와 함께 조회하고, 분류·난이도·글자로 거른다. |
| FR-22 | 진단 자유 서술 신호 | 사용자, 학습 모델 | P1 | 선택 입력한 서술에서 성향·관심사 태그를 추정하되 등급은 바꾸지 않고, 설문과 크게 다르면 확인 플래그를 남기며 원문은 저장하지 않는다. |
| FR-23 | 질문형 용어 검색 | 사용자, 학습 모델 | P1 | 용어명을 몰라도 설명형 질문으로 관련 공개 용어를 찾는다. 게시 즉시 반영된다. |
| FR-24 | 개인화 학습 경로 | 사용자 | P1 | 복습 시점 오답·서술 차이·관심사·확인 플래그·성향으로 다음 개념·용어를 사유와 함께 안내한다. |
| FR-25 | 모델 카드 공개 | 사용자 | P1 | 학습 데이터·평가 지표·기준선·쓰는 곳/쓰지 않는 곳·한계를 화면과 API로 공개한다. |
| FR-26 | 용어 운영 콘솔 | 운영자 | P1 | 새 용어 비공개 등록, 초안 저장·버리기, 검증 게시, 공개 내리기, 불변 이력, 운영 현황. |

## 증권업 학습 확장

모두 **계획**이다. 화면·API·DB 스키마는 후속 설계에서 정하며 이 작업에서는 추가하지 않았다.

| ID | 기능 | 단계 | 완료 조건 |
|---|---|---|---|
| FR-27 | 증권업 입문 경로 | 1 | 증권의 역할→발행·유통→증권회사 업무→주문·체결·청산·결제 순서로 설명하고 확인 문제·원문 출처를 제공한다 |
| FR-28 | 금융기관 비교 입문 카드 | 1 | 은행·비은행·금융투자업자의 역할을 간략 비교하고, 국내 1·2금융권 관행 표현과 공식 기관 분류를 구분한다 |
| FR-29 | 파생상품 선수학습 경로 | 1 | 현물/기초자산→선도·선물→콜·풋 옵션→손익 구조→증거금·일일 정산→헤지·레버리지 순으로 이동하고 부족한 개념으로 돌아간다 |
| FR-30 | 파생상품 구조 실험 | 1 | 가정값과 계산식 버전을 표시하고 선물과 옵션 매수·매도 손익, 프리미엄과 증거금의 차이, 가격 변화와 추가 증거금 조건을 표·그림으로 비교한다 |
| FR-31 | 과거 구간 리플레이 세션 | 2 | 이용 허가된 데이터 또는 명시된 합성 데이터를 사용하고, 의사결정 시각까지의 가격·공시·지표만 제공한다. 세션은 데이터 버전·시각·규칙·seed로 재현한다 |
| FR-32 | 판단 확정과 다음 구간 공개 | 2 | 사용자가 행동과 근거를 확정한 뒤 다음 구간을 공개한다. 다음 데이터는 공개 단계 전 클라이언트 응답·프리로드에 포함하지 않는다. 과거로 돌아가도 이미 본 세션은 새 평가로 인정하지 않는다 |
| FR-33 | 판단 회고 | 2 | 당시 가정·확정한 근거·공개된 결과·비용·기준선과 비교하고, 수익과 판단 품질을 구분해 다음 학습 개념을 연결한다 |
| FR-34 | 리플레이 표 대체 화면 | 2 | 차트와 같은 범위·정밀도·출처·날짜의 표를 제공하고 키보드만으로 결정·다음 구간 공개·회고를 완료한다 |
| FR-35 | 경량 예측 실험 | 선택 3 | 보유/이전값 등 단순 기준선을 먼저 만들고 시간 순서 walk-forward 평가, 비용·슬리피지, 구간별 실패, seed·데이터·모델 버전을 공개한다. 학습 콘텐츠와 실험 결과를 구분하고 예측을 거래 신호로 제공하지 않는다 |

FR-27~30이 1차 제품 방향이다. FR-31~34는 데이터 이용 권한·누수 검증을 통과한 뒤 추가한다. FR-35는 교육 효과와 운영 비용을 확인한 후 선택한다.
