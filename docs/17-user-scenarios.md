## S-01 처음 방문해 용어와 개념부터 둘러보기

**페르소나** P4 용어에서 막히는 입문자 · **목표** 뉴스에서 본 "가격제한폭"과 그 배경 개념을 이해한다.

**사전 조건** 로그인하지 않았다.

**기본 흐름**
1. 홈(`/`)에서 서비스가 "무엇을 살지보다, 무엇이 결과를 바꾸는지"를 배우는 곳이며 매매를 권하지 않는다는 안내와, 용어 수·모델 지표(API에서 받은 실제 값)를 본다.
2. `주식 용어 사전`을 눌러 `/glossary`로 간다. 14개 분류와 분류별 용어 수가 보인다.
3. 이름을 몰라 "주가가 하루에 너무 많이 못 오르게 막는 규칙"이라고 검색한다.
4. "질문 의미로 찾은 용어" 영역에 **가격제한폭**이 1순위로 나타난다. 글자가 일치하는 용어는 없다는 안내가 함께 보인다.
5. 용어 상세에서 정의, 상·하한가 공식, 예시(10,000원 → 7,000~13,000원), 주의할 점, 관련 용어(호가가격단위·서킷브레이커·VI), 출처(한국거래소)를 읽는다.
6. `관련 학습 개념 보기`로 `/learn?concept=volatility`에 바로 들어가 변동성 개념 카드와 확인 문제를 본다.

**대안 흐름**
- 3a. "PER"처럼 이름을 알면 글자 검색 결과와 의미 검색 결과가 함께 나오고, 의미 검색 결과에 "이름 일치" 배지가 붙는다.
- 3b. 분야·난이도 필터로 범위를 좁혀 목록을 훑어볼 수 있다.

**예외 흐름**
- 3c. 검색어가 100자를 넘으면 글자 검색은 400을 돌려주고 화면은 오류와 다시 시도를 보여 준다.

**사후 조건** 아무 기록도 저장되지 않는다(비로그인).

**검증** `GlossaryIntegrationTest`, `TermRetrievalServiceTest.용어명을_몰라도_설명형_질문으로_찾는다`, 브라우저 점검(2026-10-16).

## S-02 성향 진단 + 자유 서술 → 결과 → 다음 학습

**페르소나** P1 첫 투자 준비생 · **목표** 내 성향을 근거와 함께 알고, 무엇부터 공부할지 안내받는다.

**사전 조건** 가입·로그인했고 이번 달 진단을 하지 않았다.

**기본 흐름**
1. `/start`에서 이번 달 진단 가능 상태(FinMATE 자체 월 1회 정책)를 확인하고 `이번 달 진단 시작`을 누른다.
2. 5개 문항(목적·경험·기간·자산 비중·손실 감내)에 답한다. 진행률과 답변 완료 수가 보이며, 답하지 않으면 다음으로 넘어갈 수 없다.
3. 마지막 단계에서 투자 생각을 자유롭게 쓴다. 예: "솔직히 레버리지 ETF로 단기간에 크게 벌어 보고 싶어요. 반토막이 나도 버틸 수 있을 것 같아요." 화면은 **문장은 저장하지 않고 추정 결과만 남는다**고 안내한다.
4. `함께 제출하기`를 누르면 서버는
   1. 규칙 엔진으로 점수·등급·탐색 카테고리를 먼저 확정하고(예: 44점, 안정추구형),
   2. 자유 서술을 모델로 추정한다(공격투자형, 확신도 95%, 태그: 레버리지·파생 관심, 쏠림·추격 매수 신호),
   3. 설문 등급과 2단계 이상 차이 나고 확신도가 0.5 이상이므로 `NARRATIVE_MISMATCH` 확인 플래그를 붙이고,
   4. 원문을 버린 채 결과를 스냅샷에 저장한다.
5. `/result/:id`에서 등급(안정추구형)과 점수, AI 또는 템플릿 근거, 진단 당시 답변, "상품을 살펴보기 전에 확인해 주세요" 플래그, 자유 서술 신호 카드를 본다. 카드는 "성향 등급은 설문 답변으로만 정해집니다"라고 다시 밝힌다.
6. `이 신호로 만든 다음 학습 보기`로 `/me`에 가면 학습 경로가 나온다. 서술·설문 차이(위험감수능력과 위험수용도, 최대낙폭과 회복)가 먼저, 이어서 관심사 태그의 확률이 높은 순서로 태그마다 2개씩(레버리지 관심 → 레버리지, 레버리지 ETF와 변동성 손실 / 쏠림 신호 → 행동 편향, 과장·사기 신호) 나온다. 한 신호가 목록을 독차지하지 않고, 모든 항목에 사유가 붙는다.

**대안 흐름**
- 3a. `건너뛰고 제출`하면 서술 신호 없이 기존과 같이 진단된다. 결과 화면에는 "지금 적어 보면 비교해 준다(저장되지 않음)" 카드가 대신 나온다.
- 4a. 서술이 짧거나 주제와 무관하면 모델은 `INSUFFICIENT`로 판단을 보류하고, 결과 카드는 "서술만으로는 판단을 보류했습니다"를 보여 준다.
- 4b. 서술과 설문이 비슷하면 플래그 없이 "비슷한 방향입니다" 카드와 관심사 태그만 보인다.

**예외 흐름**
- 4c. 서술이 1,000자를 넘으면 400을 돌려준다.
- 4d. 문항·카테고리 데이터가 없으면 503과 다시 시도 화면을 보여 준다.
- 4e. AI 설명이 실패하면 템플릿 근거로 대체하고 "기본 설명" 배지를 단다(S-10).

**사후 조건** 진단 1건(이번 달), 불변 스냅샷(답변 근거·규칙 버전·문항 해시·확인 플래그·서술 추정). 자유 서술 원문은 어디에도 없다.

**검증** `NarrativeLearningPathIntegrationTest` 두 시나리오(등급 불변·원문 미저장·학습 경로 순서, 서술 생략·길이 초과), 브라우저 점검(2026-10-16).

## S-03 이번 달 진단을 이미 한 사용자의 학습 전환

**페르소나** P2 진단 제한 사용자 · **목표** 등급을 바꾸지 않고도 관심 있는 고위험 상품의 구조를 공부한다.

**기본 흐름**
1. `/start`에서 "이번 달 진단을 완료했어요"와 다음 진단 가능 시각(한국 시간), 기존 결과·학습 바로가기를 본다.
2. `/learn`에서 `파생상품과 레버리지 → 레버리지 → 레버리지 ETF와 변동성 손실` 개념을 연다(등급과 무관하게 열림).
3. 모의투자 탭에서 `leverage-decay` 시나리오를 실행해 지수가 제자리여도 2배 상품이 손실을 보는 경로를 확인한다.

**예외 흐름** 같은 달 두 번째 제출을 시도하면 409 `ASSESSMENT_MONTHLY_LIMIT`과 다음 진단일이 돌아온다. 동시 제출도 DB의 사용자·제출월 유일성 제약으로 1건만 남는다.

**검증** 월 1회 정책 제약(`assessments (user_id, submission_period) unique`), `SimulationEngineTest`(레버리지 변동성 손실 불변식).

## S-04 확인 문제 오답 → 복습 일정 → 재도전으로 해소

**페르소나** P1·P3 · **목표** 틀린 문항을 간격을 두고 다시 풀어 기억에 남긴다.

**기본 흐름**
1. 로그인 상태에서 `/learn?concept=risk-capacity`의 확인 문제를 풀고 채점한다. 정답·오답 모두 선택지별 해설과 한 줄 결론이 나온다.
2. 서버는 시도 이력(불변)과 문항별 최신 상태를 저장한다. 오답이면 다음 복습일은 1일 뒤다.
3. `/me`의 `틀린 문제` 탭에 문항, 내가 고른 답의 해설, 확인할 답의 해설이 보이고 `다시 공부하기`로 개념에 돌아간다.
4. 복습일이 되면 학습 경로의 `복습할 때가 된 항목`에 나타난다.
5. 다시 맞히면 오답노트에서 빠지고 다음 복습일이 1 → 3 → 7 → 14 → 30일로 늘어난다.

**대안 흐름** 비로그인 상태로 풀면 채점·해설은 같지만 아무것도 저장하지 않는다. 만료된 토큰을 보내면 조용히 비로그인 처리하지 않고 401을 돌려준다.

**예외 흐름** 문제를 받은 뒤 콘텐츠가 개정되면 409와 "문제를 다시 불러오세요"를 보여 준다.

**검증** `AuthProgressAdminIntegrationTest.quizAttemptsStayPrivateAndCorrectRetryClearsWrongAnswer`, `QuizReviewStateTest`.

## S-08 운영자: 새 용어 등록 → 게시 → 검색 반영 → 공개 내리기

**페르소나** P5 · **사전 조건** 서버 환경변수로 만든 관리자 계정으로 로그인했다(공개 가입으로는 관리자가 될 수 없다).

**기본 흐름**
1. `/admin/glossary`에서 운영 현황(공개 247 · 비공개 0 · 게시 대기 0 · 가입자 · 완료 진단 · 퀴즈 시도 · 모델 버전)을 본다.
2. `+ 새 용어`로 `earnings-yield`(이익수익률 = EPS ÷ 주가 = 1 ÷ PER)를 입력하고 `비공개로 만들기`를 누른다. 서버는 slug 형식, 분류·학습 개념·관련 용어 존재, 출처 URL(http/https)을 검증한다.
3. 공개 API에서는 아직 404다. `검증하고 게시`를 누르면 공개되고, 커밋 직후 검색 인덱스가 다시 만들어져 "주가 대비 이익이 몇 퍼센트인지 보는 지표" 질문에 1순위로 검색된다(공개 용어 248개).
4. 기존 용어를 고칠 때는 초안으로 저장되며 공개본은 게시 전까지 그대로다. 다른 운영자가 그사이 공개본을 바꿨다면 게시가 409로 막힌다.
5. 문제가 있는 용어는 `공개 내리기`로 즉시 용어 사전·검색에서 뺀다. 내용은 남아 있어 다시 게시하면 복귀한다.
6. `게시 이력`에 생성·게시·공개 내림이 편집자·시각과 함께 쌓인다(수정·삭제 불가).

**예외 흐름** 일반 사용자가 관리자 API를 호출하면 403, 존재하지 않는 관련 용어·학습 개념이나 잘못된 slug는 400, 중복 slug는 409.

**검증** `AdminGlossaryLifecycleIntegrationTest` 두 시나리오, 브라우저 점검(2026-10-16).

## S-09 세션 만료·로그아웃과 보호 화면 복귀

1. 로그인하면 30일짜리 세션이 발급되고 서버에는 토큰의 SHA-256만 저장된다. 서버를 재시작해도 세션은 유지된다(영구 DB 기준).
2. 로그인하지 않은 채 `/admin/glossary`나 `/me`에 들어가면 로그인 화면으로 가고, 로그인 후 **원래 화면으로 돌아온다**(외부 주소로는 보내지 않는다).
3. 로그아웃하면 서버 세션이 폐기되어 같은 토큰으로 `/auth/me`를 호출하면 401이다.
4. 앱을 다시 열면 저장된 토큰을 `/auth/me`로 확인하고, 만료됐으면 로그인 상태를 지운다.

**검증** `AuthProgressAdminIntegrationTest.sessionsPersistHashedTokensExpireAndLogoutRevokesThem`.

## S-10 외부 AI 장애·모델 산출물 누락 시 동작

| 상황 | 동작 | 사용자에게 보이는 것 |
|---|---|---|
| `ANTHROPIC_API_KEY` 없음·타임아웃·출력 검증 실패 | 진단 근거와 개념 설명을 결정적 템플릿으로 대체 | "기본 설명" 배지. 등급·카테고리는 정상 |
| 자유 서술 근거 부족·주제 무관 | 성향 추정 보류 | "판단을 보류했습니다" |
| 모델 JSON 누락·손상 | **기동 실패**(조용히 동작하지 않음) | 배포 단계에서 발견 |
| 용어·개념 JSON의 출처 누락, 깨진 관련 용어·개념 링크 | **기동 실패** | 배포 단계에서 발견 |
| 진단 문항·카테고리 없음 | 503 `ANALYSIS_UNAVAILABLE` | 다시 시도 화면 |
