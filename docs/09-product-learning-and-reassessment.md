# 09. 상품 이해 학습과 재진단 정책

## 문제 정의

초기 FinMATE는 진단을 원하는 만큼 다시 실행할 수 있어 점수를 원하는 방향으로 맞추는 행동과 결과의 재현성 문제가 있었다. 반대로 안정형으로 분류된 사용자가 더 위험한 상품을 찾을 때에는 단순 차단만으로는 이해를 돕지 못한다.

## 확정 제품 정책

- 이 과제 서비스는 **한국 시간 기준 달력 월 1회**만 진단 제출을 허용한다. 금융사의 공통 규정이라고 표현하지 않으며 `monthly-kst-v1` 정책 버전으로 표시한다.
- 중복 제출은 DB의 사용자·제출월 유일성 제약으로 막는다. 동시 제출도 같은 제약으로 수렴한다.
- 다음 진단일, 기존 결과 보기, 상품 기초 학습으로 이동하는 경로를 차단 화면에 제공한다.
- 기존 등급이 안정형이라는 이유만으로 상품 지식을 숨기지 않는다. 안내 범위를 벗어난 상품도 위험·유동성·비용의 기초 개념을 학습할 수 있게 한다.
- 교육 카드는 가입·매매·등급 상향을 유도하지 않는다. 상품 설명서와 공식 위험 정보를 확인하도록 한다.

## 실제 현업 메커니즘과의 경계

검색한 금융기관 사례에는 온라인 투자자성향 확인서의 **일일 횟수 제한**이 있고, 재평가 사유가 있을 때 추가 평가를 허용하는 운영도 있다. 따라서 월 1회는 FinMATE의 제품 정책으로 명시하고 실제 금융기관 정책으로 일반화하지 않는다. 실제 서비스화 시에는 재진단 사유, 변경된 고객정보, 상담·증빙, 기존 결과의 유효기간을 별도 정책으로 검토한다.

## 결과 재현성

진단 완료 시 답변의 질문·선택지 문구, 규칙 버전, 질문지 SHA-256 버전, 주의 플래그를 불변 JSON 스냅샷으로 저장한다. 이후 질문 시드가 바뀌어도 결과 화면은 당시 기록을 사용한다. 스냅샷이 없는 이전 데이터는 추정 복원하지 않고 근거 미제공 상태를 표시한다.

## 기초 학습 카드

- 위험과 수익: 수익 가능성과 손실 가능성을 함께 읽는다.
- 채권: 발행자 신용위험, 금리 변동에 따른 중도 매도 가격 위험을 확인한다.
- ETF: 분산 가능성 외에 시장가격-NAV 차이, 스프레드, 비용, 기초자산 위험을 확인한다.
- 유동성: 팔 수 있는지와 원하는 가격·시간에 현금화할 수 있는지는 다르다.

## 인수 기준

- 한 사용자의 같은 달 두 번째 제출은 409와 다음 진단일을 반환한다.
- 동시 제출에서도 완료 진단은 월 1건이다.
- 완료 결과에는 답변 근거와 규칙/질문지 버전이 표시된다.
- LLM 설명이 등급 변경, 특정 상품 권유, 수익률 예측, 200자 초과를 포함하면 템플릿 설명으로 대체한다.
- 이력에서 같은 버전의 두 완료 결과를 선택하면 변경된 답변을 보여주며, 버전이 다르면 직접 비교하지 않는다.
- `/learn`은 재진단 제한과 무관하게 접근할 수 있다.
