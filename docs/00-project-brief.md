# 00. 프로젝트 개요 (Project Brief)

> 상태: 확정(Fixed) — 이후 문서는 이 문서를 기준으로 작성한다.
> 변경 시 반드시 [changelog.md](changelog.md)에 기록한다.

## 서비스명

**FinMATE** — AI 기반 투자 성향 진단 및 금융상품 탐색 서비스

## 한 줄 설명

사용자의 투자 목적과 위험 감수 성향을 AI가 분석하고, 분석 근거와 함께 적합한 금융상품 카테고리와 예시 상품을 탐색하도록 돕는 웹 서비스

## 배경 (왜 만드는가)

- 투자 초보자는 자신의 위험 감수 성향과 투자 목적을 객관적으로 파악하기 어렵다.
- 기존 금융 서비스는 상품 정보는 제공하지만, "왜 이 상품이 나에게 맞는지"에 대한 근거를 제공하지 않는다.
- 사용자의 답변(투자 목적, 투자 기간, 손실 민감도 등)을 AI가 해석하여 성향을 분류하고, 그 판단 근거를 자연어로 설명해 주는 서비스가 필요하다.

## 타깃 사용자

투자를 시작하고 싶지만 자신의 투자 성향과 적합한 상품을 판단하기 어려운 **금융 초보자**

## 핵심 가치

1. 진단 질문 → 규칙 기반 성향 판정 → AI 근거 설명 → 상품 카테고리 탐색까지 하나의 흐름으로 연결
2. "추천"이 아니라 "근거 있는 탐색"에 집중 (실제 매매·수익 보장·투자 자문 없음)
3. 내부 위험 필터를 통과한 카테고리 안에서 사전 등록된 예시 상품을 탐색할 수 있음

## 1차 Agile 주요 기능 (P0)

- 투자 성향 진단 질문 응답
- AI 기반 투자 성향 분석 및 근거 제공
- 성향에 맞는 금융상품 카테고리 안내
- 안내 카테고리의 예시 상품 목록·상세 탐색

## 2차 Agile 확장 후보 (P1)

- 개별 상품 비교
- 가상 포트폴리오 저장
- 관리자용 질문·상품 관리
- 자연어 자유 입력 및 진단 이력 비교

상세 기능 목록과 액터별 요구사항은 [01-requirements.md](01-requirements.md) 참고.

## 명시적 제외 범위 (이번 과제 범위 아님)

- 실제 증권계좌 연동, 실제 매수·매도 주문
- 수익률 보장, 실시간 주가 분석·예측
- 개인별 세금·법률 자문

> 이유는 [05-decisions.md](05-decisions.md) ADR-001 참고.

## 성공 기준

사용자가 로그인 후 모든 진단 문항에 답하면, (1) 5단계 투자 성향과 점수 산출 근거를 확인하고, (2) 내부 탐색 기준으로 안내된 금융상품 카테고리와 해당 카테고리의 예시 상품을 탐색할 수 있어야 한다. LLM 설명 생성이 실패해도 규칙 기반 설명으로 결과를 확인할 수 있어야 하며, 문항·카테고리 데이터가 준비되지 않은 경우에는 오류 안내와 재시도 경로가 보여야 한다.

> 1차 완료 여부는 기능 수가 아니라 위 핵심 흐름이 요구사항 → 화면 → 데이터 → API에서 끊김 없이 추적되는지로 판단한다. 상세 완료 조건은 [06-mvp-review-and-handoff.md](06-mvp-review-and-handoff.md) 참고.
