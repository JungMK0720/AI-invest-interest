# 증권업 학습 로드맵

기준일: 2026-10-26. 아래는 새 제품의 **계획**이며 이번 정리에서 기능을 추가하지 않았다.

## 1단계: 증권업과 상품 구조

| 순서 | 내용 | 확인 과업 | 연결 |
|---|---|---|---|
| 1 | 증권이 무엇이며 왜 필요한가: 자금 조달과 투자자의 권리 | 주식·채권의 권리와 자금 흐름 구분 | UR-20, FR-27 |
| 2 | 은행·증권회사와 국내 1·2금융권 간략 소개 | 기관의 업무를 위험 순위와 구분 | UR-21, FR-28 |
| 3 | 증권회사 중개·인수·기업금융·자산관리 | 기업 발행과 투자자 거래의 참여자 연결 | UR-20, FR-27 |
| 4 | 발행·유통, 주문·체결·청산·결제 | 주문부터 소유권·대금 이동까지 설명 | UR-20, FR-27 |
| 5 | 주식·채권·펀드·ETF | 권리·비용·유동성·손실 요인 비교 | 기존 FR-10~14 |
| 6 | 현물·기초자산→선도·선물 | 양쪽 계약 의무와 일일 정산, 만기 손익 계산 | UR-22, FR-29·30 |
| 7 | 콜·풋 옵션 | 매수자의 권리·프리미엄과 매도자의 의무·증거금 구분 | UR-22, FR-29·30 |
| 8 | 증거금·추가 납부·헤지·레버리지 | 가격 변화가 필요한 자금과 손실에 미치는 영향 설명 | UR-22, FR-29·30 |

**마진은 맥락을 구분한다.** 파생상품의 margin은 계약 이행을 위한 증거금이며 옵션 프리미엄과 다르다. 증권 신용거래의 margin buying/lending은 차입·이자·담보·강제청산의 구조를 다룬다. 선물은 양쪽 의무, 옵션은 매수자 권리와 매도자 의무의 비대칭을 먼저 설명한다.

기초자산부터 시작하는 순서는 [한국거래소 파생상품 정의](https://www.krx.co.kr/contents/OPN/01/01040100/OPN01040100.jsp)를 바탕으로 한 제품 제안이다. 계약 이행 담보와 증거금의 역할은 [한국거래소 증거금 제도](https://regulation.krx.co.kr/contents/RGL/03/03050500/RGL03050500T1.jsp)를 참조한다. 실제 제도 수치와 교육용 가정은 구분한다. 출처 확인일: 2026-10-26.

첫 출시 판정은 콘텐츠·출처 검수, 핵심 경로·권한 확인, [NFR의 단계 0~1 부하 목표](../requirements/nonfunctional-requirements.md) 검증 후 한다.

## 2단계: 과거 차트 판단과 회고

루프는 `시점 고정 → 당시 정보 확인 → 행동·근거 확정 → 다음 구간 공개 → 비용 포함 결과 → 회고·복습`이다. 초기 범위는 한 종목·한 구간·단순 비용 모델로 제한한다. 현금 유지·판단 보류도 선택지로 검토한다.

| 경계 | 요구 |
|---|---|
| 데이터 이용 | 이용·보존·재배포 조건 확인. 합성 데이터면 화면에 명시 |
| 관측 시각 | 사건 발생일과 실제 공개 시각 구분. 당시 미공개 정보 제외 |
| 차트·표 동등성 | 날짜·가격·단위·공개 범위 일치. 표·키보드만으로 과업 완료 |
| 공개 경계 | 다음 데이터는 UI뿐 아니라 응답·정적 파일·프리로드에도 포함하지 않음 |
| 데이터 처리 | 전체 기간 정규화 금지. 조정주가·구성종목·사후 정정·상장폐지 편향 점검 |
| 결정 기록 | 데이터 버전·현재 시점·행동·근거·규칙·비용·seed·공개 이력 보존 |
| 회고 | 당시 판단 품질과 사후 수익 구분. 틀린 근거로 이익 난 선택도 검토 |
| 평가 공정성 | 이미 다음 구간을 본 세션은 연습으로 구분하고 새 평가로 집계하지 않음 |

실시간 시세·멀티플레이·랭킹은 필수가 아니다. FR-31~34, NFR-16·17 검증과 데이터 권한 확보가 선행 조건이다.

## 선택 3단계: 경량 예측 실험

이 단계는 퀀트의 데이터·검증 방법을 경험하는 입문 실험이다. 다음 구간 방향 분류처럼 목표를 하나만 정하고 로지스틱 회귀 등 작은 모델 하나로 시작한다. 대규모 모델 학습이나 자동매매 시스템은 이번 로드맵의 필수 산출물이 아니다.

1. 예측 대상·시점·기간과 특징 생성 규칙을 고정한다.
2. 이전값 유지·변화 없음 등 문제에 맞는 단순 기준선을 먼저 측정한다.
3. 과거로 학습하고 이후를 평가하는 walk-forward를 사용한다. 겹치는 라벨 기간은 간격을 검토한다.
4. 모델·기준선에 같은 거래 비용·슬리피지를 적용한다. 예측 오차와 전략 손익을 따로 본다.
5. 튜닝에 쓰지 않은 최종 구간, 실패 구간, 데이터·모델·seed·설정·한계를 공개한다.
6. 기준선보다 못하거나 학습 효과가 없으면 기능 확대를 보류한다.

랜덤 시계열 분할, 평가 구간으로 정규화·특징 선택, 좋은 구간만 보고하는 결과는 채택하지 않는다. 예측 모델 없이 1·2단계를 배포할 수 있다. 연결: UR-25, FR-35, NFR-18.
