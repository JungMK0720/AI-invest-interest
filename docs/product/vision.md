# 제품 비전

기준일: 2026-10-26. FinMATE의 다음 목적은 **증권업을 이해하고, 상품 구조를 배우고, 과거 사례에서 판단 근거를 연습하는 학습 서비스**다. 성향 진단과 AI는 이 학습을 돕는다.

## 사용자가 얻을 것

1. 증권이 왜 필요하며 기업·투자자·증권회사·거래소가 어떻게 연결되는지 설명한다.
2. 현물에서 출발해 선물·옵션·증거금·파생상품의 손익과 위험 구조를 이해한다.
3. 과거의 제한된 정보로 판단한 뒤 다음 결과를 공개하고 자기 근거를 돌아본다.

성과는 용어 개수나 단기 수익률만으로 판정하지 않는다. 개념 설명, 손익·위험 계산, 모르는 정보 구분, 잘못된 근거 수정 여부를 확인한다. 실제 사용자 검증은 아직 하지 않았다.

## 범위와 순서

첫 출시는 증권업 입문과 상품 구조 학습이다. 은행·증권회사와 국내 1·2금융권은 전체 지도를 이해할 만큼 짧게 다루고, 발행·유통, 증권회사 업무, 거래·청산·결제, 주식·채권·펀드·ETF, 파생상품으로 깊이를 더한다.

다음 단계는 과거 차트 게임이다. 그 시점에 알 수 있었던 정보로 행동과 근거를 확정한 뒤 다음 구간을 공개한다. 동일 데이터를 표로 제공해 차트 해석 숙련도가 참여 조건이 되지 않게 한다.

예측 모델은 선택 단계다. 단순 기준선보다 의미가 있는지 시간 순서 평가와 비용을 포함해 확인하는 학습 실험으로 둔다. 모델 추가는 첫 배포의 완료 조건이 아니다.

실계좌·실주문 연결, 개인별 투자 권유, 수익 보장은 현재 범위 밖이다. 기존의 규칙 기반 판정·AI 설명 검증·템플릿 폴백·출처 보존 원칙을 유지한다.

## 기존 자산

| 기존 자산 | 새 방향에서의 역할 | 상태 |
|---|---|---|
| 용어·개념·확인 문제 | 증권업 학습 경로 재료 | 기존 구현, 새 경로는 계획 |
| 시뮬레이션·포트폴리오 실험 | 상품 구조·가정 변화 확인 | 기존 구현, 새 과업은 계획 |
| 성향 진단·근거 스냅샷 | 자기 이해와 다음 학습 연결 | 기존 구현 |
| 오답노트·복습·학습 경로 | 오류 수정과 재학습 | 기존 구현 |
| 자체 모델·모델 카드·LLM | 보조 신호·검색·설명·한계 공개 | 기존 구현 |
| 외부 데이터 경계·DBML | 과거 구간 리플레이 설계 재료 | 실데이터 미연동 |

기존 구현은 소스가 존재한다는 뜻이며 organization 배포 완료를 의미하지 않는다.

## 공식 자료와 제품 제안의 구분

한국은행 교육 자료는 은행과 비은행금융기관을 구분하고 증권회사 등을 비은행 영역의 예로 설명한다. 1·2금융권 표현을 간단히 소개하되 실제 기관 역할을 기준으로 가르친다. [한국은행 금융기관의 종류](https://www.bok.or.kr/portal/bbs/B0000216/view.do?menuNo=200648&nttId=10000085&pageIndex=&type=PEPL)

증권결제는 증권 소유권 이전과 매매대금 결제의 과정이다. 이를 바탕으로 주문 이후의 절차를 학습 과업으로 제안한다. [한국은행 금융하부구조](https://www.bok.or.kr/portal/main/contents.do?menuNo=200320)

파생상품의 가치는 기초자산 가격 변화와 연결되며 선물은 그 한 종류다. 따라서 기초자산을 먼저 배우고 선물·옵션을 연결하는 순서를 제안한다. [한국거래소 파생상품이란](https://www.krx.co.kr/contents/OPN/01/01040100/OPN01040100.jsp)

출처 확인일: 2026-10-26. 학습 순서·과업은 위 자료를 바탕으로 한 제품 설계 제안이다. 기관이 권장한 공식 교육 과정이라고 주장하지 않는다. 증거금률·기본예탁금·교육 시간 등 바뀌는 수치는 콘텐츠 작성 시 공식 자료로 다시 확인한다.
